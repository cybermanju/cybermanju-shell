Política de Privacidade — CyberManju OS

Última atualização: 8 de outubro de 2026 · CyberManju OS v0.1.1 (código aberto, licença MIT)

O CyberManju OS é um gerenciador de arquivos criptografados local-first: seus dados vivem no seu dispositivo, dentro de um cofre criptografado (.cybermanju). Não operamos servidores próprios que recebam seus arquivos. Esta página explica quais dados do Google acessamos, por quê e como são tratados — ela atende aos requisitos da tela de consentimento OAuth do Google.

1. Dados que acessamos via Google

  • Identidade (escopos openid email profile): nome, e-mail e foto do perfil — usados apenas para mostrar quem está conectado na tela de Contas.
  • Google Drive (escopo https://www.googleapis.com/auth/drive.file): visualizar e gerenciar somente os arquivos e pastas que o próprio CyberManju OS cria, ou que você abre explicitamente com o aplicativo. Não temos acesso ao restante do seu Drive.

2. Como usamos esses dados

  • Autenticar você (login via Google, intermediado pelo Supabase Auth do seu projeto configurado em Configurações → OAuth).
  • Sincronizar seu cofre criptografado com a pasta do aplicativo no seu Google Drive.
  • Nada mais. Não exibimos anúncios, não fazemos perfilamento e nenhum humano lê seus arquivos.
Uso limitado (Google API Services User Data Policy).
The use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements: Google user data is used only to provide or improve the user-facing features of CyberManju OS, never sold, never used for advertising, and never shared except as required by law or with your explicit consent.

3. Onde seus dados ficam

  • Tokens OAuth: guardados apenas no seu navegador (armazenamento local / arquivo de cofre) ou no cofre de segredos do seu sistema operacional na versão desktop. Nunca são enviados a servidores nossos.
  • Arquivos: criptografados no seu dispositivo (ChaCha20Poly1305 + criptografia pós-quântica ML-KEM) antes de qualquer upload. O Google recebe apenas blobs criptografados.
  • Troca OAuth: executada pelo Supabase Auth (projeto que você configurou). Consulte também a política do seu provedor Supabase.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos seus dados com terceiros, exceto quando exigido por lei. O código-fonte é público (cybermanju/cybermanju.github.io), para que qualquer pessoa possa auditar exatamente o que o aplicativo faz.

5. Revogar o acesso / apagar dados

  • Revogue o acesso do app a qualquer momento em myaccount.google.com/permissions.
  • No app: Contas → Sign out e apague o arquivo .cybermanju para remover todos os dados locais.
  • Revogar no Google invalida o token em até 1 hora (tokens de acesso do Google duram ~1h); o app então pede nova conexão.

6. Contato

Dúvidas sobre privacidade: cybermanju.os@gmail.com.

7. Alterações

Atualizaremos esta página quando o tratamento de dados mudar; a data no topo indica a versão vigente.
